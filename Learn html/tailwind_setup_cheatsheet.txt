🟢npm install
Downloads all required packages into node_modules, npm install is the one that downloads node modules.
It reads package.json to know what to download aka uses package.json as the instruction list.
Node modules is like the actual engines/tools.
This because package.json says "tailwindcss" "vite" "postcss" etc.
Once npm install finishes: Tailwind and Vite live locally in node_modules, it will still work even without internet or if tailwinds website disappear

Tailwind’s real code lives in node_modules/tailwindcss, Vite’s real code lives in node_modules/vite.
Your config files just tell those tools how to behave.

🟢When you upload your work to the internet, you upload everything except node_modules, and dist.
You cannot reuse node_modules because its huge and can break on another machine.
The server will then run npm install and npm run build.
if you create a new javascript file, create it under src/ and then import : import './app.js'-  all your project code lives in src/.


If tailwind or vite updates you can update manually by npm update, or safely use: npm install tailwindcss@latest vite@latest -D
This will manually update all three: package.json (version numbers change), node_modules (new code is downloaded), package-lock.json (lockfile updated).


🟢Vite is a development and build tool for modern web projects.
It is a super-fast local server while you code, it is a builder that prepares your site for production.
During development(npm run dev), vite is used to start a local server, instantly reload page when you save a file, and it also handles modern javascript imports.
and it makes Tailwind updates appear instantly.
Vite = fast dev server + production builder.
