A stylesheet in web development is a file (usually `.css` or `.scss`) that defines how HTML elements should look 
including layout, colors, fonts, spacing, and responsiveness.


🟢SASS is a CSS pre-processor of CSS. It reduces repetition of CSS and therefore saves times.
Sass stands for Syntactically Awesome Stylesheet
It is an extension to CSS.
It has the ".scss" file extension.

🟢Sass supports standard CSS comments- /* comment */, it supports inline commments // comment:
https://sass-lang.com/,  sass-lang.com/install

You write the sass styling in your scss file and then your csss file is automatically created by the SCSS compiler.
Your HTML only loads main.css You never upload SCSS to the browser.
if your CSS file is inside a css folder, you must use: <link rel="stylesheet" href="css/main.css">

Unless the CSS file is in the same folder as the HTML: <link rel="stylesheet" href="main.css">

If using a scss compiler (like Live Sass Compiler), then every time you save the SCSS file, it will automatically update the CSS file too.

🟢Sass uses the $ symbol, followed by a name, to declare variables: $variablename: value;

Sass stores infor in variables like strings, numbers, colors, booleans, lists, and nulls.
$myFont: Helvetica, sans-serif;
$myColor: red;
$myFontSize: 18px;

h1 {
  font-family: $myFont;
  color: $myColor;}

If it had h1{$myColor: green;} p{color: $myColor} it'll be green because it was now define locally not globally. However p will sill be red.

h1{$myColor: green; !global} p{color: $myColor} everything will now be green both h1 and p, because !global has override the variable scope.

another variable form
:root {
  --success: #22c55e;
  --warning: #facc15;
  --danger: #ef4444;
}


🟢SASS Nesting
Sass also lets you nest CSS selectors in same way as HTML like: <nav><ul<li><a> </nav></ul</li></a>. Eg-
nav {
  ul {
    margin: 0;
    padding: 0;
    list-style: none;
  }
  li {
    display: inline-block;
  }
  a {
    display: block;
    padding: 6px 12px;
    text-decoration: none;
  }
}

CSS would have been: nav ul {
  margin: 0;
  padding: 0;
  list-style: none;
}


🟢CSS properties have the same prefix, like font-family, font-size and font-weight or text-align, text-transform and text-overflow.

With Sass you can write them as nested properties: eg-
font: {
  family: Helvetica, sans-serif;
  size: 18px;
  weight: bold;
}

text: {
  align: center;
  transform: lowercase;
  overflow: hidden;
}

The Sass transpiler will convert the above to normal CSS:
font-family: Helvetica, sans-serif;
font-size: 18px;
font-weight: bold;

text-align: center;
text-transform: lowercase;
text-overflow: hidden;

🟢@import used to include the content of one file in another. Lets say there is a file named reset.scss with content:
html, body, ul, ol {margin: 0; padding: 0;} you will import it as @import "reset"; it will then be transpiled to css.

Files named with an underscore like _filename.scss are Sass partials, and they are only meant to be imported into other .scss files.
They are not compiled into standalone CSS on their own. So it's best to name an imported file with underscore '_'.
// _variables.scss
$primary-color: #ff6600; // create.scss @import 'variables';

🟢@mixin- directive lets you create CSS code that is to be reused throughout the website.
The @include directive is created to let you use (include) the mixin.
EG: @mixin name {
  property: value;
  property: value;
  ...
}

@mixin important-text { 		.danger{
  color: red;					 @include important-text;
  font-size: 25px;				 background-color: green;
  font-weight: bold;				}
  border: 1px solid blue;
}


.danger {
  color: red;
  font-size: 25px;
  font-weight: bold;
  border: 1px solid blue;
  background-color: green;
}

Define mixin:
@mixin text-style($size, $color) {	.title{
 font-size: $size;				@include text-style(32px, red)
  color: $color;			       }
}
Css output.title {
  font-size: 32px;
  font-weight: bold;
  color: blue;
}

🟢@extend is used to share a set of CSS properties from one selector to another.
.button-basic  {
  border: none;
  padding: 15px 30px;
  text-align: center;
  font-size: 16px;
  cursor: pointer;
}

.button-report  {
  @extend .button-basic;
  background-color: red;
} So you can inherit the style and also add another one like the background collor


CSS Output
.button-basic, .button-report, .button-submit {
  border: none;
  padding: 15px 30px;
  text-align: center;
  font-size: 16px;
  cursor: pointer;
}

.button-report  {
  background-color: red;
}
