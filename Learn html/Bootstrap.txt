🟢Bootstrap is a popular front-end framework that uses HTML and CSS to make responsive web pages. faster and easier.
Bootstrap provides a responsive grid system, prebuilt component, javascript plugins, and extensive customisation.

You can add its CSS and JavaScript to your HTML. Do this by linking content delivery network (CDN) or by downloading the source files directly.

🟢To use a CDN, set up an HTML file with its responsive viewport meta tag in the <head> section.
then add the link tag for Bootstrap's CSS inside the <head> section of the document.
Link the JavaScript. Place <script> tag for the Bootstrap JavaScript bundle before the closing </body> tag.
This bundle includes Popper.js and is required for all interactive components.
CDN requires no installatino.

🟢Boostrap can also be installed via package managers like npm, RubyGems, Composer, or Meteor.
: npm install bootstrap@5.3.8
Provides access to the source files and allows for more advanced customisation.
Developers can download source files and include them in their project manually.

You can then copy the bootstrap and popperjs files or folder into project.
Then link them in css like this: <link rel="stylesheet" href="css/bootstrap.min.css">
<script src="js/bootstrap.bundle.min.js"></script>
 
or the easiest CDN: <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
