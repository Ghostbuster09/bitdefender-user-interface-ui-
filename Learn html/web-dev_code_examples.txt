🟢Universal selector- (*)
*{
   margin:0;
   padding:0;
   box-sizing: border-box;
} margin:0; and padding: 0;

This is the "Reset", removes all default spacing so that your layout behaves predictably.
This is because every web browser has a built-in "User Agent Stylesheet", this applies default styles and spacing to HTML elements so that a  plain text is readable.
the <body> tag usually has an 8px margin, which creates a white gap around your website and <h1> tags have large and bottom margins.

box-sizing: border-box; This changes how width is calculated. 
       Without this: width + padding + border = total size.
       With this: width includes the padding and border.
       Example: A 100px div with 20px padding stays 100px wide, 
       instead of growing to 140px.

🟢CSS Animations
To use CSS animation, you must specify some keyframes for the animation
@keyframes myAnimation{from {background-color: red;} to {background-color: yellow;} then apply it like div{animation-name: myAnimation;}
instead of using from and to it is possible to use percentage from= represents 0% and to= 100%complete. Using percentage means you can add many style.

@keyframes myAnimation {
  0%   {background-color: red;} 25%  {background-color: yellow;} 50%  {background-color: blue;} 100% {background-color: green;} }
div{animation-name: myAnimation.}

Animation Shorthand Property- div{animation: myAnimation 5s linear 2s infinite alternate;}
